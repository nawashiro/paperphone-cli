# Spec Delta

## Purpose

組み上がった冊子を、朝の無人実行でも壊れない形で A4 横向き・モノクロの PDF として書き出す能力。

## ADDED Requirements

### Requirement: 用紙と色

書き出される PDF は A4 横向きで、文字と画像をモノクロ（グレースケールまたは黒）で描かなければならない (SHALL)。ページ数は1ページ、地図が有効な場合だけ2ページとする。

#### Scenario: 地図なしの冊子

- **WHEN** 地図を無効にして生成する
- **THEN** PDF は A4 横向き1ページで、すべての内容がモノクロになる

#### Scenario: 地図ありの冊子

- **WHEN** 地図を有効にし、出発地と目的地を設定して生成する
- **THEN** PDF は2ページになり、2ページ目に180度回転した地図ページが入る

### Requirement: 原子的なファイル書き出し

PDF は出力先と同じディレクトリの一時ファイルに書き、完成してから出力先へ置き換えなければならない (SHALL)。出力先の親ディレクトリが無ければ作り、既存のファイルは置き換える。成功時は出力先の絶対パスを標準出力に出して終了コード0で終わる。

#### Scenario: 既定の名前で書き出す

- **WHEN** `--out` を指定せずに実行する
- **THEN** カレントディレクトリに `paperphone-YYYY-MM-DD.pdf` が作られ、その絶対パスが標準出力に出る

#### Scenario: 親ディレクトリが無い

- **WHEN** `--out ~/paper/2026/11/today.pdf` を指定し、`2026/11` が無い
- **THEN** ディレクトリが作られ、PDF が書き出される

#### Scenario: 既存の PDF を置き換える

- **WHEN** 同じ `--out` に前日分の PDF がある状態で実行する
- **THEN** 前日分は同じ名前の新しい PDF に置き換わり、古い内容は残らない

### Requirement: 書き出し失敗時の完全性

描画または書き出しに失敗した場合、出力先に不完全な PDF を残してはならない (MUST NOT)。一時ファイルを削除し、理由を標準エラーに出して終了コード1で終わる。

#### Scenario: 書き込みに失敗する

- **WHEN** 出力先のファイルシステムが読み取り専用である
- **THEN** 出力先には何も残らず、終了コード1で理由が表示される

#### Scenario: 描画に失敗する

- **WHEN** 冊子の描画中に例外が発生する
- **THEN** 一時ファイルは削除され、既存の出力先ファイルは変更されない
