# Spec Delta

## MODIFIED Requirements

### Requirement: 枠の構成と順序

冊子の1ページ目は A4 横向きで、4列2段の8つの枠を持たなければならない (SHALL)。上段は左から 連絡先・予定・タスク・写真、下段は左から メモ・表紙・天気・紙アプリ の固定順で並び、各枠は約54mm×85mm、ページの外周に約10mmの余白を取る。設定で有効にした項目だけが中身を持ち、地図が有効なら2ページ目に地図を置く。

#### Scenario: 全項目を選んで生成する

- **WHEN** 8項目と地図をすべて有効にして生成する
- **THEN** 1ページ目に8つの枠が固定順で並び、2ページ目に地図が印刷される

#### Scenario: 地図だけを外す

- **WHEN** 地図以外の項目だけを有効にして生成する
- **THEN** 冊子は1ページだけになる

#### Scenario: 一部の項目だけを有効にする

- **WHEN** 連絡先と予定だけを有効にして生成する
- **THEN** 連絡先と予定の枠に中身が入り、残りの6枠は空き枠になる

### Requirement: 表紙

表紙の枠には、設定の名前を大文字にしたもの・「PHONE」・指定タイムゾーンでの生成日を印刷しなければならない (SHALL)。表紙は下段の2番目の枠に固定される。

#### Scenario: 表紙を確認する

- **WHEN** 名前「Aki」で `--tz Asia/Tokyo` を指定して生成する
- **THEN** 表紙の枠に「AKI'S」「PHONE」と東京の日付が印刷される

#### Scenario: UTC と東京で日付が違う

- **WHEN** UTC ではまだ前日だが東京では翌日になっている時刻に生成する
- **THEN** 表紙の日付は東京の日付になる

## ADDED Requirements

### Requirement: 設定による項目の選択

冊子に載せる項目は設定ファイルの `[panels]` で選ばなければならない (SHALL)。有効な項目は中身を持ち、無効な項目は空き枠になる。地図は `[panels].map` で制御し、無効なら2ページ目を作らない。

#### Scenario: 天気を無効にする

- **WHEN** `[panels]` で天気を無効にして生成する
- **THEN** 天気の枠は点の空き枠になり、天気の取得も行われない

#### Scenario: 項目を何も有効にしない

- **WHEN** `[panels]` が空の状態で生成する
- **THEN** 表紙と7つの空き枠だけの1ページが作られる

#### Scenario: 知らない項目名を書く

- **WHEN** `[panels]` に存在しない項目名を書いて実行する
- **THEN** 設定エラーとして終了コード2で終わり、PDF は書き出されない

## REMOVED Requirements

### Requirement: ダッシュボードでの項目選択

**Reason**: CLI にはダッシュボードが無く、選択は実行時ではなく設定時に行う。

**Migration**: 設定ファイルの `[panels]` で項目を選ぶ。

### Requirement: ダッシュボードの表示

**Reason**: CLI にはダッシュボードが無い。

**Migration**: 名前は `[booklet].name`、日付は表紙と PDF の内容で確認する。

### Requirement: 冊子の生成開始

**Reason**: CLI は起動そのものが生成の開始であり、生成ボタンが無い。

**Migration**: `paperphone` を実行する。項目が空でも表紙と空き枠の冊子が作られる。

### Requirement: コンタクトレスの切り取り線

**Reason**: 物理カードを差し込むための切り取り線は CLI 版の範囲外とする。

**Migration**: 必要な場合は紙アプリまたはメモの枠を使う。
