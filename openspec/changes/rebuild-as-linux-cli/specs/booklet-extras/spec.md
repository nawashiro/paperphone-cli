# Spec Delta

## MODIFIED Requirements

### Requirement: 写真の選択

写真を有効にした場合、設定の `photo.path` が指す画像1枚を冊子の写真の枠に使わなければならない (SHALL)。取り込めるのは常に1枚で、パスを変えれば前の写真は置き換わる。パスが無い、読めない、または画像として解釈できない場合は警告を出し、写真の枠を点の空き枠にする。

#### Scenario: 写真を選ぶ

- **WHEN** `photo.path` に縦長の JPEG を指定して生成する
- **THEN** その画像が白黒に変換され、写真の枠に使われる

#### Scenario: 写真を選ばずに写真の項目を選ぶ

- **WHEN** 写真を有効にしたが `photo.path` が無い
- **THEN** 写真の枠は点の空き枠として印刷され、冊子は完成する

#### Scenario: 存在しないパスを指定する

- **WHEN** 読めないファイルパスを `photo.path` に指定する
- **THEN** 警告が出て写真の枠は空き枠になり、他の内容で PDF が書き出される

### Requirement: 紙アプリの選択

紙アプリの枠には、設定の `paper_app.name` で選んだ同梱の読み物を、縦横比を保たず枠いっぱいに引き伸ばして印刷しなければならない (SHALL)。選べるのは換算表・結び方・イタリア語会話・手話・九九表・レシピ・折り紙の鳩・数独・迷路・今日の単語・アナグラム・なぞなぞ・タイポグラフィの13種類で、未指定なら折り紙の鳩を使う。

#### Scenario: 紙アプリを選ぶ

- **WHEN** `paper_app.name = "sudoku"` で生成する
- **THEN** 紙アプリの枠に数独が枠いっぱいに印刷される

#### Scenario: 別の紙アプリを選び直す

- **WHEN** 数独を指定したあと `paper_app.name = "maze"` に変えて生成する
- **THEN** 枠には迷路だけが印刷される

#### Scenario: 紙アプリを選ばずに紙アプリの項目を選ぶ

- **WHEN** 紙アプリを有効にしたが `paper_app.name` を書かない
- **THEN** 折り紙の鳩が印刷される

#### Scenario: 知らない紙アプリ名を書く

- **WHEN** 存在しない名前を `paper_app.name` に書く
- **THEN** 設定エラーとして終了コード2で終わり、PDF は書き出されない
