# maps Specification

## Purpose

設定した出発地から目的地までの徒歩の道順を、白黒の地図と住所の組として冊子の2ページ目に印刷する能力。紙を持って歩くためのページになる。

## Requirements

### Requirement: 出発地と目的地の指定

地図を有効にした場合、設定の `[maps].from` と `[maps].to` の緯度経度・表示名・住所を使い、現在地の取得や地点検索は行わない (SHALL)。どちらかが欠けている、または範囲外なら設定エラーとして終了コード2で拒否する。

#### Scenario: 設定した2地点を使う

- **WHEN** `[maps].from` と `[maps].to` に自宅と駅を書いて生成する
- **THEN** その2地点を結ぶ徒歩経路の地図が印刷される

#### Scenario: 目的地が無い

- **WHEN** 地図を有効にしたが `[maps].to` を書かずに実行する
- **THEN** 終了コード2で終わり、PDF は書き出されない

#### Scenario: 範囲外の緯度

- **WHEN** `[maps].from.latitude` に 100 を書いて実行する
- **THEN** 終了コード2で終わり、PDF は書き出されない

### Requirement: 経路の種類

設定された経路サービスから徒歩の経路を1本取得し、距離や所要時間は印刷せず、経路の線を地図の上に黒で描かなければならない (SHALL)。経路サービスが未設定の場合は地図だけを印刷する。

#### Scenario: 徒歩経路を印刷する

- **WHEN** 経路サービスを設定して地図を有効にする
- **THEN** 徒歩の経路が黒い線で描かれた地図が印刷され、距離や所要時間は印刷されない

#### Scenario: 経路サービスが未設定

- **WHEN** 経路サービスを設定せずに地図を有効にする
- **THEN** 経路の線は描かれず、地図と A・B の印だけが印刷される

### Requirement: 地図ページの内容

地図は冊子の2ページ目にだけ印刷し、「MAPS」の見出し、出発地の A と目的地の B の印、LEAVING FROM と GOING TO の見出し付きの住所、白黒に変換した地図を載せなければならない (SHALL)。地図の下には手書き用の点の領域を残し、地図の隅に「© OpenStreetMap contributors」の帰属を印刷する。

#### Scenario: 地図ページを確認する

- **WHEN** 地図を有効にして生成する
- **THEN** 2ページ目に地図と A・B の印、出発地と目的地の住所、OpenStreetMap の帰属が印刷される

#### Scenario: 住所が長い

- **WHEN** 住所が「通り, 市区郡, 国」のように区切られている
- **THEN** 住所は2行に分けて印刷される

### Requirement: 地図ページの向き

2ページ目は用紙の裏面に印刷される前提で、ページ全体を180度回転して描かなければならない (SHALL)。あわせて折り畳みの基準になる小さな円を2つ印刷する。

#### Scenario: 地図ページの向き

- **WHEN** 地図を含む冊子を両面印刷する
- **THEN** 折り畳んだときに地図が正立して読める

### Requirement: 経路が取れないとき

経路の取得に失敗した場合でも、地図の画像と見出し・印・住所・点の領域を印刷し、冊子の生成を止めない (SHALL)。地図タイルの取得に失敗した場合は地図の画像だけを省き、経路の線も描かない。

#### Scenario: 経路の取得に失敗する

- **WHEN** 経路サービスに到達できない状態で生成する
- **THEN** 2ページ目には地図と見出し・印・住所・点の領域が印刷され、経路の線だけが無い

#### Scenario: 地図タイルの取得に失敗する

- **WHEN** タイル提供元に到達できない状態で生成する
- **THEN** 2ページ目には見出し・印・住所・点の領域だけが印刷され、冊子は完成する
