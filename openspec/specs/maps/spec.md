# maps Specification

## Purpose

今いる場所から行き先までの徒歩の道順を、白黒の地図と住所の組として冊子の裏面に印刷する能力。紙を持って歩くためのページになる。

## Requirements

### Requirement: 出発地と目的地の決定

地図の画面は出発地の初期値として現在地を表示し、目的地は地点検索から選ばせなければならない (SHALL)。出発地が取得できないときはロンドンの地点を、目的地を選ばなかったときはロンドンの別の地点を既定として使う。

#### Scenario: 現在地から目的地まで

- **WHEN** 目的地を検索して選ぶ
- **THEN** 現在地を出発地、選んだ場所を目的地とした経路が作られる

#### Scenario: 目的地を選ばずに生成する

- **WHEN** 目的地を選ばないまま地図を選んで生成する
- **THEN** 既定のロンドンの2地点で経路の地図が印刷される

#### Scenario: 出発地を選び直す

- **WHEN** 出発地の欄をタップして検索から別の場所を選ぶ
- **THEN** その場所が新しい出発地になる

### Requirement: 経路の種類

アプリは徒歩の経路を1本だけ取得し、距離や所要時間は印刷しなければならない対象に含めない (SHALL)。経路の線は地図の上に黒で描く。

#### Scenario: 徒歩経路を印刷する

- **WHEN** 地図を選んで生成する
- **THEN** 徒歩の経路が黒い線で描かれた地図が印刷され、距離や所要時間は印刷されない

### Requirement: 地図ページの内容

地図は冊子の2ページ目にだけ印刷し、「MAPS」の見出し、出発地の A と目的地の B の印、LEAVING FROM と GOING TO の見出し付きの住所、白黒に変換した地図を載せなければならない (SHALL)。地図の下には手書き用の点の領域を残す。

#### Scenario: 地図ページを確認する

- **WHEN** 地図を選んで生成する
- **THEN** 2ページ目に地図と A・B の印、出発地と目的地の住所が印刷される

#### Scenario: 住所が長い

- **WHEN** 住所が「通り, 市区郡, 国」のように区切られている
- **THEN** 住所は2行に分けて印刷される

### Requirement: 地図ページの向き

2ページ目は用紙の裏面に印刷される前提で、ページ全体を180度回転して描かなければならない (SHALL)。あわせて折り畳みの基準になる小さな円を2つ印刷する。

#### Scenario: 地図ページの向き

- **WHEN** 地図を含む冊子を両面印刷する
- **THEN** 折り畳んだときに地図が正立して読める

### Requirement: 両面印刷の案内

アプリは地図を選んだ場合、両面印刷に対応したプリンタが必要であることを画面に表示しなければならない (SHALL)。

#### Scenario: 地図の画面を開く

- **WHEN** 地図の画面を開く
- **THEN** 両面印刷が必要である旨の案内が表示される

### Requirement: 経路が取れないとき

経路の取得に失敗した場合でも、アプリは生成を止めず、地図の画像を除いた見出し・印・住所・点の領域だけを印刷しなければならない (SHALL)。

#### Scenario: 経路の取得に失敗する

- **WHEN** 経路の取得が失敗して生成する
- **THEN** 2ページ目には地図の画像を除いた内容だけが印刷され、冊子は完成する
