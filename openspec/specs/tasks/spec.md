# tasks Specification

## Purpose

EDS の VTODO から未完了のタスクを読み、やることと期限を冊子のタスク枠に印刷して、紙の上でチェックできるようにする能力。

## Requirements

### Requirement: タスクリストの読み取り

タスクの枠は、設定の `[sources].tasks` に列挙した VTODO の source から、未完了のタスクを読まなければならない (SHALL)。Google Tasks は対象外とする。読み取りに失敗した source は警告を出して飛ばし、他の source だけで冊子を作る。

#### Scenario: VTODO を読む

- **WHEN** Nextcloud のタスクリストを `[sources].tasks` に書いて生成する
- **THEN** そのリストの未完了タスクがタスクの枠に印刷される

#### Scenario: 読み取りに失敗する

- **WHEN** 認証が切れたタスクリストを選んで生成する
- **THEN** 警告が出てそのリストは飛ばされ、残りの内容で PDF が書き出される

### Requirement: タスクリストの選択

設定の `[sources].tasks` で複数のタスクリストを同時に選べなければならない (SHALL)。選択は設定ファイルに残り、次回の実行でも使われる。

#### Scenario: 2つのリストを選ぶ

- **WHEN** 2つのタスクリストの UID を `[sources].tasks` に書いて生成する
- **THEN** 両方のリストのタスクが1つの枠にまとめて印刷される

#### Scenario: リストのチェックを外す

- **WHEN** 選んでいたリストの UID を設定から消して生成する
- **THEN** そのリストのタスクは冊子に含まれない

### Requirement: タスクの印刷内容

タスクの枠には「TASKS」の見出しを印刷し、タスクごとに空の丸とタスク名を並べなければならない (SHALL)。タスク名は枠の幅に収まらない部分を切り詰める。

#### Scenario: タスクを印刷する

- **WHEN** 「牛乳を買う」を含むリストを選んで生成する
- **THEN** タスクの枠に丸と「牛乳を買う」が印刷され、紙の上でチェックできる

### Requirement: タスクの並び順

タスクは期限の早い順に並べ、期限が同じものと期限の無いものはタスク名の昇順で並べなければならない (SHALL)。期限の無いタスクは期限のあるタスクの後ろに置く。

#### Scenario: 期限の違うタスク

- **WHEN** 明日が期限のタスクと今日が期限のタスクを含めて生成する
- **THEN** 今日が期限のタスクが先に印刷される

#### Scenario: 期限の無いタスク

- **WHEN** 期限のあるタスクと期限の無いタスクを含めて生成する
- **THEN** 期限の無いタスクは期限のあるタスクの後ろに印刷される

### Requirement: 期限の表記

期限のあるタスクには、期限が指定タイムゾーンで今日なら「Today」、明日なら「Tomorrow」と印刷しなければならない (SHALL)。それ以外の期限と期限の無いタスクには何も印刷しない。

#### Scenario: 今日が期限のタスク

- **WHEN** 今日が期限のタスクを含めて生成する
- **THEN** そのタスクの下に「Today」が印刷される

#### Scenario: 明日が期限のタスク

- **WHEN** 明日が期限のタスクを含めて生成する
- **THEN** そのタスクの下に「Tomorrow」が印刷される

#### Scenario: 期限のないタスク

- **WHEN** 期限の無いタスクを含めて生成する
- **THEN** そのタスクの下には何も印刷されない

### Requirement: 書き込み用の空き枠

タスクが9件未満のときは空の丸を、9件になるまで加えて印刷しなければならない (SHALL)。9件以上のときは空の丸を加えない。印刷するタスクは最大9件とし、10件以上ある場合は並び順の先頭9件だけを印刷する。

#### Scenario: タスクが2件のとき

- **WHEN** タスクが2件のリストを選んで生成する
- **THEN** 枠にはタスク2件と空の丸7つが印刷される

#### Scenario: タスクが8件のとき

- **WHEN** タスクが8件のリストを選んで生成する
- **THEN** 枠にはタスク8件と空の丸1つが印刷される

#### Scenario: タスクが9件を超えるとき

- **WHEN** タスクが11件のリストを選んで生成する
- **THEN** 枠には並び順の先頭9件だけが印刷され、空の丸は印刷されない
